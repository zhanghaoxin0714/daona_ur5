# 导纳控制算法流程图

## 算法输入 (Inputs)

### 1. 导纳参数矩阵
```python
M = np.diag([0.2, 0.2, 0.05, 0.008, 0.008, 0.01])  # 质量矩阵 (6×6)
B = np.diag([20, 20, 20, 20, 20, 20])              # 阻尼矩阵 (6×6)  
K = np.diag([50, 50, 100, 30, 30, 30])             # 刚度矩阵 (6×6)
```

### 2. 当前状态数据
```python
pose_current = [x, y, z, rx, ry, rz]     # 当前位姿 (基坐标系)
pose_target = [x, y, z, rx, ry, rz]      # 目标位姿 (基坐标系)
force_base = [Fx, Fy, Fz, Tx, Ty, Tz]    # 外力 (基坐标系)
dt = 0.005                               # 控制周期 (5ms)
```

### 3. 历史状态数据
```python
pose_previous = [x, y, z, rx, ry, rz]   # 前一时刻位姿
de_previous = [dx, dy, dz, drx, dry, drz] # 前一时刻速度误差
dde_previous = [ddx, ddy, ddz, ddrx, ddry, ddrz] # 前一时刻加速度误差
```

---

## 算法计算过程 (Computations)

### 步骤1: 位姿误差计算
```python
# 当前时刻位姿误差
e_current = pose_current - pose_target
# 输出: e_current = [ex, ey, ez, erx, ery, erz] (6×1)
```

### 步骤2: 速度误差计算
```python
# 当前时刻速度误差
d_pose_current = (pose_current - pose_target) / dt
# 输出: d_pose_current = [dx, dy, dz, drx, dry, drz] (6×1)
```

### 步骤3: 加速度误差计算
```python
# 当前时刻加速度误差
dd_pose_current = (d_pose_current - d_pose_previous) / dt
# 输出: dd_pose_current = [ddx, ddy, ddz, ddrx, ddry, ddrz] (6×1)
```

### 步骤4: 导纳控制方程求解
```python
# 导纳控制方程: M*d²e/dt² + B*de/dt + K*e = F
# 求解加速度增量
dde_current = np.diag(1 / np.diag(M)) @ (force_base - B @ de_previous - K @ e_previous)
# 输出: dde_current = [ddx, ddy, ddz, ddrx, ddry, ddrz] (6×1)
```

### 步骤5: 速度增量计算
```python
# 梯形积分计算速度增量
de_current = de_previous + dt * (dde_current + dde_previous) / 2
# 输出: de_current = [dx, dy, dz, drx, dry, drz] (6×1)
```

### 步骤6: 位姿增量计算
```python
# 梯形积分计算位姿增量
e_current = e_previous + dt * (de_current + de_previous) / 2
# 输出: e_current = [ex, ey, ez, erx, ery, erz] (6×1)
```

### 步骤7: 状态更新
```python
# 更新历史状态，为下一时刻计算做准备
pose_previous = pose_current
de_previous = de_current
dde_previous = dde_current
e_previous = e_current
```

---

## 算法输出 (Outputs)

### 主要输出
```python
pose_increment = e_current  # 位姿增量 [ex, ey, ez, erx, ery, erz] (6×1)
```

### 输出含义
- **位置增量**: [ex, ey, ez] - 在基坐标系X、Y、Z轴上的位置变化量 (m)
- **姿态增量**: [erx, ery, erz] - 在基坐标系X、Y、Z轴上的旋转变化量 (rad)

## 算法特点

### 1. 定点控制
- **目标位姿** = **当前位姿**
- 实现"定点柔顺"控制
- 外力作用下产生位姿偏移

### 2. 积分控制
- 使用梯形积分方法
- 保证数值稳定性
- 避免积分漂移

### 3. 实时控制
- 控制频率: 200Hz (5ms周期)
- 实时响应外力变化
- 闭环反馈控制

### 4. 坐标统一
- 所有物理量在基坐标系下表示
- 确保数学和物理一致性
- 便于参数调节和理解
